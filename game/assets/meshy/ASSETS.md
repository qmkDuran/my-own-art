# Meshy assets

Every asset here was made with the Meshy API through the budget guard (spend_log.jsonl in the scratchpad). Pipeline: an image
(text-to-image for the 3 concepts; image-to-image with a concept as the style reference for every asset), then image-to-3D with
`meshy-t2.5` geometry (smart topology) and the `meshy-n1` stylised texture (15 credits). Characters were made in A-pose, rigged
(5 credits, which also returns walking and running clips) and animated from the library (3 credits per action).

Style lock used in every prompt: *stylised cozy storybook 3D, soft rounded shapes, chunky proportions, hand-painted textures, warm
muted colours, like a cozy animated film; game asset; clean silhouette*.

Repo copies were made smaller with `tools/shrink_glb.py` (textures to JPEG: 1024 px for props and characters, 2048 px for
buildings) and each character's clips were merged into one GLB with `tools/merge_clips.py` (clips: idle, walk, run, talk, sit, wave).
Concept images are not in the repo (they were only references).
